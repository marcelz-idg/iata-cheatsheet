Ideal Postcodes

Pros

  • Cheapest option across all three platforms
  • Single API call returns all addresses — simple and predictable billing
  • Closest to the current Codeberry integration — least refactoring required
  • Free sandbox with test key, no signup needed
  • Daily Royal Mail PAF refresh
  • Live developer chat

Cons

  • Smaller company than Loqate — less enterprise track record
  • No mention of formal SLA uptime guarantee

Data8

Pros

  • ISO 27001, global coverage, daily PAF refresh
  • Single API call — same simple billing model as Ideal Postcodes
  • Reliable mid-tier option between Ideal Postcodes and Loqate on price
  • Public status page

Cons

  • £9,000/yr more expensive than Ideal Postcodes across all platforms
  • Developer support details not clearly published
  • Trial requires registration — no instant sandbox

Loqate

Pros

  • Industry leader — largest global address dataset
  • ISO 27001, comprehensive global coverage
  • Well-documented API with strong enterprise support
  • Public status page and formal SLA

Cons

  • Two-step API: Find (free) + Retrieve (billed per address selected, not per search) — more complex to integrate correctly and easy to over-consume credits if not implemented carefully
  • Most expensive option and requires a custom quote
  • Trial is very limited: 35 address retrievals per day
  • Pricing less transparent than competitors
Recommendation: Ideal Postcodes is the strongest choice — lowest cost, simplest API, closest to the current implementation, and the only provider with an instant test sandbox. Data8 is a solid fallback if a more established name is preferred. Loqate is premium but its two-step billing model adds integration complexity and makes trial evaluation difficult.
