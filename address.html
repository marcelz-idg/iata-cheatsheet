ISO 27001 • Global • ~£30,200/yr

Register at data-8.co.uk for a free trial key

Trial note: Data8 requires manual activation of API access on free trial accounts — email info@data-8.co.uk to request it. Type-ahead

Uses PredictiveAddress service (POST) — one country at a time, passed as country in the JSON body. Fires after 300ms; retrieve on click is billed.

Loqate

ISO 27001 • Global • Quote required

Register at loqate.com for free trial credits

Trial limit: 35 lookups/day. Each address returned costs 1 credit — a single postcode search can use up to 25 credits. If the limit is exceeded, it resets at midnight. Contact Loqate to request a higher evaluation limit.

Type-ahead

Searches GB & US simultaneously — Countries=GB,US comma-separated in one query param. Find is free; Retrieve (billed) only triggers on click.

Ideal Postcodes

Pros

  • Cheapest option — ~£21,140/yr across all platforms
  • Single GET call returns the full address list instantly
  • Simple, predictable billing — charged per postcode lookup
  • No signup needed to evaluate — free sandbox key (ak_test) built in
  • Lowest integration complexity — straightforward response, easy field mapping
  • Type-ahead via /autocomplete/addresses — fuzzy matching, sub-100ms, two-step (find free + resolve billed)
  • Daily Royal Mail PAF refresh
  • Live developer chat support
  • UK/EU data centres only — strong GDPR/data residency posture

Cons

  • Smaller, specialist company compared to Data8 and Loqate
  • No formal published SLA
  • Global autocomplete limited to GBR and USA contexts currently

Data8

Pros

  • ISO 27001, well-established UK data quality company
  • Single API call returns full address list — simple billing model
  • Returns granular PAF fields (building number, name, street components separately) — precise field mapping to form
  • Broader data services beyond address lookup (phone, email validation)
  • Type-ahead via PredictiveAddress service — supports Search → DrillDown → Retrieve pattern
  • Multi-region Azure hosting (8 regions) — UK South available for data residency requirements
  • Support was responsive — activated trial API access same day

Cons

  • ~£9,000/yr more expensive than Ideal Postcodes across all platforms
  • Trial requires manual activation by their support team — not self-serve
  • Global search requires a different endpoint (PredictiveAddress) from UK postcode lookup (AddressCapture) — two separate services to integrate
  • Contact email listed on their website (info@data8-8.co.uk) is incorrect — actual address is info@data-8.co.uk
  • Developer docs less polished than competitors

Loqate

Pros

  • Industry leader — owned by GBG (FTSE-listed), largest global dataset (249+ countries, rooftop accuracy in 120+)
  • ISO 27001, comprehensive global coverage including international addresses
  • Well-documented API, strong enterprise support, formal SLA
  • Country parameter is optional — most flexible for international use cases
  • Type-ahead is the simplest upgrade path — existing Find API already works as autocomplete, no extra endpoint needed
  • Trusted by major banks, retailers and airlines worldwide

Cons

  • Two-step API: Find (free) + Retrieve (billed per address selected) — higher integration complexity, lazy retrieval pattern required to avoid over-spending
  • Most expensive option — requires a custom quote, less pricing transparency
  • Trial limited to 35 address retrievals per day — limits evaluation depth
  • Hosting infrastructure details not publicly disclosed — specific cloud regions/providers require contacting GBG directly
  • Russia excluded — address data not updated since Ukraine invasion
Recommendation: Ideal Postcodes

All three providers were fully tested and confirmed working during this evaluation. Based on the findings, Ideal Postcodes is the recommended choice. It is the cheapest option (~£21,140/yr across AGW, VGW and IDG2.0), has the simplest integration (single GET call, straightforward field mapping), and is the only provider with a zero-friction sandbox — no signup or manual activation required. For type-ahead, it provides a dedicated /autocomplete/addresses endpoint with fuzzy matching. All data stays in UK/EU data centres, making it the strongest option for data residency compliance. It was working in under 2 minutes.

Data8 is a solid alternative with a clean single-call API and granular PAF field responses. It is ~£9,000/yr more expensive than Ideal Postcodes. For type-ahead and global search it uses a separate PredictiveAddress service — meaning two different endpoints to integrate vs one for Ideal Postcodes. Multi-region Azure hosting with UK South available. Worth considering if the wider Data8 data quality services (phone, email validation) are already in scope.

Loqate is the enterprise-grade option backed by GBG (FTSE-listed) with the largest global dataset (249+ countries) and a formal SLA. Notably, it has the simplest type-ahead upgrade path — the existing Find API already works as autocomplete with no additional endpoint. However, it has the most complex billing model (two-step Find + Retrieve, billed per address selected), the highest cost (custom quote required), the most restrictive trial (35 retrievals/day), and hosting details are not publicly disclosed. Best suited if international coverage, a formal SLA, or an existing GBG relationship is a priority.

On global search: All three support 240+ countries, but country must be specified upfront for Ideal Postcodes and Data8. Loqate is the most flexible — the Countries parameter is optional, letting it search globally without pre-selecting a country. Loqate's Russia data is also not being updated (supplier decision post-Ukraine invasion).
